구글 시트 연동 & GitHub 올리기 안내

1 구글 스프레드시트 앱스 스크립트(GAS) 설정

  1. 새 구글 스프레드시트를 하나 만듭니다.
  2. 상단 메뉴에서 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.
  3. 기존 코드를 모두 지우고 아래 스크립트 코드를 붙여넣습니다.
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    
    // 헤더가 없으면 자동 작성
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(["제출일시", "학번/이름", "기분온도", "신체상태", "감정단어", "오늘의다짐"]);
      sheet.getRange(1, 1, 1, 6).setFontWeight("bold").setBackground("#dcfce7");
    }
    
    sheet.appendRow([
      data.timestamp,
      data.studentInfo,
      data.moodTemp + "°C",
      data.bodyTemp,
      data.emotions.join(", "),
      data.resolution
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ result: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ result: "error", error: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. 오른쪽 상단 [배포] ➔ [새 배포]를 누릅니다.
  2. 톱니바퀴 ⚙️ 아이콘 클릭 ➔ [웹 앱] 선택
  3. 액세스 권한이 있는 사용자를 모든 사용자 (Anyone) 로 설정 후 [배포] 클릭!
  4. 생성된 웹 앱 URL을 복사하여 상단 ⚙️ 설정 아이콘 눌러 연동 URL란에 붙여넣으면 완료!

2 GitHub에 올려서 QR코드로 출석부 배포하기

  • GitHub 저장소(Repository)를 새로 만들고 이 파일 이름은 index.html 로 업로드합니다.
  • 저장소의 Settings ➔ Pages 메뉴에서 Source를 main branch 로 설정하면 웹사이트 주소가 생성됩니다.
  • 생성된 웹사이트 주소를 네이버/구글 QR코드 생성기에 넣어서 교실 칠판이나 책상에 붙여두면 완성됩니다! 📱✨
